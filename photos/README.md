# Photos

Originals for the site's photo gallery (JPEG, PNG, WebP, TIFF or HEIC). The iPhone
"Post to Website" shortcut uploads here; the "Build photo gallery" Action turns them into
metadata-stripped web copies in `assets/gallery/` and updates `gallery.json`.
This folder itself is not published on the website. See ../GALLERY.md for the full setup.

Captions: a `.txt` next to the photo with the same name, or an entry in `captions.json`.
